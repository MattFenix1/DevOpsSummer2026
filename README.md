# Video Game Library

## This program is a .NET Web Application to add, remove, update, and search for games you have/want/are currently playing. This application is for someone who wants one place to keep everything organized with a sorting feature.

## Uses:
    -ASP .NET Core
    -ASP .NET Web API
    -(Server)
    -Entity Framework Core

## Feature
    -Add Games
    -Edit Games
    -Delete Games
    -Search Games
    -Sort Games
    -Responsive Web Interface
